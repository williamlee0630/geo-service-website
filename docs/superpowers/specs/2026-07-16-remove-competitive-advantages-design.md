# 移除 Competitive Advantages 區塊設計規格

日期：2026-07-16

## 目的

讓自我介紹網站更聚焦於個人定位、實作案例與合作內容，避免以偏技術或教學式的說明打斷閱讀節奏。

## 變更範圍

- 完整移除 `#advantages` 區塊，包含英文眉標、標題、說明文字與六張卡片。
- 不新增替代區塊或補充文案。
- 不調整其他區塊的內容、樣式與順序。
- 移除後，頁面由「合作會處理哪些問題」直接銜接「優化不是一次完成」。

## 驗收條件

- 頁面中不再出現 `#advantages`。
- 頁面中不再出現 `Competitive Advantages` 與「小型網站怎麼和大型網站競爭」。
- `#services` 後的下一個主要內容區塊是 `#process`。
- 既有網站檢查全部通過，且沒有變更其他原始文案。

## 不在本次範圍

- 不重寫服務、流程、關於我或常見問題區塊。
- 不調整導覽列、首頁影片與響應式版面。
- 不新增新的行銷或技術說明。
