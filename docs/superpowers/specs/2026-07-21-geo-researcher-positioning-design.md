# GEO 實驗研究者定位改版設計

日期：2026-07-21

## 目標

將網站的主要印象從「提供 GEO 優化服務」調整為「持續進行 GEO 實驗與研究的人」，同時保留能獨立建置網站、整理內容架構與觀察數據的實作能力。

網站不主動銷售服務；合作能力由研究過程和成果自然證明。

## 範圍與限制

- 維持現有兩個主要區塊：案例首屏與個人簡介。
- 不新增研究方法、實驗索引、服務項目或聯絡行動區塊。
- 保留現有左文右影片、下方左圖右文的桌面版面。
- 保留現有深色研究室視覺、配色、字體、主要間距與響應式方式。
- 不更換影片、個人照片與網站圖示。
- 改動集中於文案、資訊層級和必要的小型文字樣式。

## 定位層級

1. 主身份：持續進行 GEO／AEO 實驗與研究的資料科學學生。
2. 次要能力：能將研究問題轉化為網站、內容架構、技術設定與數據觀察。
3. 證據：一個小型網站出現於 AI 摘要的查詢錄影。
4. 態度：承認生成式搜尋的機率性，不把單次結果寫成可保證的成效。

## 區塊一：研究案例

這個區塊由「成功案例」改為「研究紀錄」，但維持現有 HTML 結構和版面。

### 資訊順序

1. 研究編號與觀察類型。
2. 一個有明確對象的實驗標題。
3. 研究問題與執行方式的摘要。
4. 影片呈現的可觀察結果。
5. 結果限制與後續觀察意義。

### 文案方向

- `Case Study / 01` 改為 `Research Note / 01`。
- `AI 摘要引用實證` 改為 `生成式搜尋觀察`。
- 主標題使用「一次 GEO 實驗的觀察紀錄」，不使用「實例呈現」或服務名稱當標題。
- 主導文案說明：這是針對小型、低權重網站的 GEO 實作觀察，目標是理解內容如何被搜尋引擎與生成式 AI 辨識。
- 證據文案只陳述「這次查詢中出現於 AI 摘要」，不宣稱穩定排名、可複製成功或打敗競爭者。
- 使用第一人稱單數「我」，取代「我們團隊」與「施作」。

## 區塊二：個人簡介

這個區塊建立研究者的動機、方法和實作能力，不改變現有照片與雙欄版面。

### 資訊順序

1. 身分與持續研究的問題。
2. 實驗方法：先釐清問題，再分開處理內容、技術與數據。
3. 為了驗證研究而建立的實作能力。
4. 關注低權重網站的原因與後續方向。

### 文案語氣

- 使用第一人稱與具體動機，保留學生與研究中的真實身分。
- 不使用「專家」、「領先」、「全方位」、「協助客戶」等銷售型字詞。
- 保留 Next.js、HTML／CSS、GA4、Search Console 與結構化資料等能力，但要說明它們如何支撐研究，不只是關鍵字羅列。
- 技能標籤保留，必要時調整文字，不增加數量。

## 全站文字一致性

- 導覽的「成功案例」改為「研究紀錄」；「關於我」保留。
- 網站標題、description、Open Graph 與 Person JSON-LD 改為研究者定位，不使用服務銷售語言。
- 圖片 alt、影片 title、頁尾與行動選單文字同步更新，避免新舊定位並存。
- 不製作客製網域、聯絡方式或尚未提供的履歷資料。

## 實作與驗收

- 盡量只修改 `index.html` 內容；不拆分新檔案或引入新套件。
- 只在新文案造成版面問題時微調 CSS。
- 維持桌面與行動版的現有內容順序、影片播放、選單開關與錨點連結。
- 更新現有靜態內容測試的預期文字。
- 執行現有測試，並檢查沒有殘留「成功案例」、「我們團隊」、「施作」等舊定位文字。
- 以桌面與 390px 寬度各檢視一次，確認沒有文字溢出、不合理斷行、重疊或明顯的區塊高度失衡。

## 不在本次範圍

- 新增第三個主要區塊。
- 新增更多案例、部落格、實驗資料庫或內容管理系統。
- 新增接案表單、服務價格或強式合作按鈕。
- 重新設計視覺系統、導覽架構或動畫。
